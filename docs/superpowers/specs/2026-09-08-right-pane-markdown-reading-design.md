## Модель рабочей области

Правая рабочая область остаётся единой: **Diff**, **Files** и **Documents** являются её достижимыми представлениями. Когда открыт хотя бы один документ, переходы к Diff и Files сохраняются. Открытие Documents не заменяет и не скрывает остальные два представления.

Documents хранит набор одновременно открытых страниц. Например, спецификация и план могут быть открыты и переключаться без вытеснения друг друга. У каждой страницы есть режимы **Read**, **Source** и **Changes**:

- новая страница открывается в **Read**;
- **Source** показывает исходный текст Markdown;
- **Changes** показывает изменения страницы относительно доступной базы;
- обновление входных данных сохраняет вручную выбранные страницу и режим, если они ещё существуют;
- если выбор больше недействителен, выбирается безопасный существующий документ и его режим по умолчанию Read.

Выбор файла `.md` в Files открывает либо активирует связанную страницу Documents. Файлы других типов сохраняют обычное поведение Files.

## Поведение данных и ошибок

Отсутствие совпадающего diff не препятствует Files, Documents, Read или Source: Changes показывает «изменений нет». Пока snapshot рабочей области недоступен, Changes показывает загрузку, не подменяя её состоянием без изменений. Ошибки открытия сообщаются существующими безопасными notices. Если позднее не удаётся прочитать связанный файл, страница сохраняет последний хороший snapshot, а навигация и Source остаются доступны. Контракт не вводит отдельное структурированное поле ошибки для каждой страницы.

Кэш Markdown-рендера ограничен по размеру и ключуется идентификатором страницы, сигнатурой содержимого, шириной и параметрами, влияющими на рендерер. Поэтому содержимое другого документа или новая сигнатура не получают устаревший результат. Source и Changes выводятся из текущей страницы, snapshot рабочей области и режимного UI-состояния, а не из общего кэша Markdown. Контракт не требует буквального поля сессии или режима в каждом ключе кэша.

Копирование и hit testing используют одну геометрию отрисовки, включая двухъячеечный левый отступ правой рейки. Координаты за пределами содержимого не выбирают Markdown-элемент. Копируется только явно выбранный текст или безопасно представимый текст ссылки, без выполнения ссылок, команд или интерпретации Markdown как доверенного кода.

Пути документов проверяются существующими границами рабочей области. Рендерер не раскрывает содержимое вне разрешённого контекста, не выполняет HTML, скрипты, внешние команды и сетевые загрузки. Ссылки и изображения не создают новый сетевой канал.
